2. 번역이 두 갈래인 이유

이 앱의 글자는 성격이 둘로 나뉩니다. 그래서 번역 방식도 둘입니다.

① 번호표 — 파일에 박힌 글자

화면 마크업에 처음부터 적혀 있는 글자입니다. 자리마다 번호를 새겨 두고, 언어를 바꾸면 그 번호의 값을 쓰기만 합니다. 글자를 읽지 않으므로 빠릅니다(전체 40ms).

<div data-k="436,437,439">   ← 이 요소의 텍스트 자리 번호
  Lighter than a cup of coffee
  <span data-k="438">₩330 a day</span>
</div>

cgo-pack-ru[436] = "Легче чашки кофе"
cgo-pack-ru[438] = "₩330 в день"

② 사전 — 눌러야 생기는 글자

팝업 내용, 계산 결과, AI 답변처럼 JS가 만들어 넣는 글자입니다. 화면에 없으니 번호를 붙일 수 없어, 한국어를 열쇠로 사전을 찾습니다.

cgo-ui-ru = { "별 충전소": "Звёздная станция", ... }

지금 남은 일은 전부 ②쪽입니다. 번호표는 6개 언어 모두 채워져 있습니다. 페이지 본문이 92% 러시아어인 게 그 증거입니다. 사전만 채우면 팝업도 따라옵니다.

3. 한국어가 새지 않는 이유

사전에 그 언어 값이 없으면 영어로 내려갑니다. 한국어는 사용자에게 보이지 않습니다.

자기 언어 있음  →  자기 언어
        없음  →  영어
한국어는 어떤 경우에도 노출되지 않음

이 규칙은 세 곳에 모두 들어 있습니다 — _cgoT(통짜), _cgoTNode(페이지·팝업 본문과 placeholder·title), 그리고 코드 안의 언어 분기 _cgoTX/_cgoTP/_cgoTV.

5. 겪었던 함정 — 다시 밟지 마세요

자리 번호가 밀린다

칠할 때마다 "빈 글자는 건너뛰기"로 번호를 다시 세면, 번역값이 공백처럼 보일 때 그 자리를 건너뛰어 이후 번호가 한 칸씩 밀립니다. 배너에 ₩330 в день, 즉 ₩10 за функцию으로 같은 혼용이 났던 원인입니다.

→ 번호는 노드에 __cgoK로 한 번만 새기고 그 뒤로는 그것만 씁니다.

번호가 마지막에 말해야 한다

옛 장치들(setLang·사전 적용·페이지 부활 감시기)이 부팅 뒤에도 돌면서 번호가 칠해 놓은 자리를 덮어씁니다.

→ setLang 직후와 700·2000·4000·7000ms에 번호를 다시 확정합니다.

사전을 거꾸로 뒤지지 말 것

_cgoRecoverKO는 영어를 한국어로 되돌립니다. 외국어 화면에서 돌면 혼용이 납니다.

→ 한국어일 때만 실행되게 막아 두었습니다.

JS가 만든 페이지는 열 때 번역

작명·음악·주식 페이지는 내용을 JS가 넣습니다. 팝업의 appendChild 길목을 타지 않습니다.

→ cgoGoPage에서 그 페이지만 한 번 번역합니다.

6. 속도 — 건드리면 안 되는 것들

장치왜 이렇게 두었나
지명 목록 data-noxl출생지 자동완성 13,078개가 한국어 글자의 99%였음. 번역 대상이 아닌데 매번 훑고 있었음
팝업 backdrop-filter 제거오버레이 151곳이 화면 전체를 매 프레임 흐리게 그림 — 팝업이 걸리는 느낌의 주범
팝업 등장 0.14초 통일원래 0.2초~2.5초로 제각각이라 앱이 굼떠 보였음
붙이는 길목 후킹팝업 94개 중 5개만 삽입 전 번역이었음. 이제 전부 화면에 붙기 전에 번역됨

7. 검사하는 법

브라우저 콘솔에 그대로 붙여 넣으면 그 언어에 남은 한국어를 셉니다.

(function(){
  var n=0, s=[];
  document.querySelectorAll('[id^="page-"]').forEach(function(p){
    (function w(x){
      if(x.nodeType===3){
        var v=(x.nodeValue||'').trim();
        if(v && /[\uac00-\ud7a3]/.test(v)){ n++; if(s.length<10) s.push(v.slice(0,30)); }
        return;
      }
      if(x.nodeType!==1) return;
      if(x.tagName==='SCRIPT'||x.tagName==='STYLE'||x.tagName==='OPTION') return;
      for(var i=0;i<x.childNodes.length;i++) w(x.childNodes[i]);
    })(p);
  });
  return { 남은한국어:n, 표본:s };
})()

성씨·지명·가수 이름이 나오면 정상입니다. 그 밖의 문장이 나오면 사전에 채울 대상입니다.
