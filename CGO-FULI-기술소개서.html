CGO-FULI의 핵심 가치 — 헌법 v2.0

1. 정직 100% 헌법

CGO-FULI는 글로벌 빅테크와는 정반대의 길을 갑니다. 빅테크는 사용자 데이터를 수집하여 광고 수익을 올리지만, 우리는 단 1바이트의 데이터도 외부로 전송하지 않습니다.

🔒 CGO-FULI 헌법 v2.0 (3대 원칙)

① ZERO STORAGE — 사용자 데이터는 폰 안에만 저장, 서버 X
② ZERO SERVER — 외부 API 통신 0건, 온디바이스 처리만
③ ZERO COST — 사용자 비용 하루 330원, 글로벌 최저가

2. 왜 정직이 1위를 만드는가

① 글로벌 규제 청정 (GDPR · CCPA · HIPAA 프리패스)

유럽 GDPR, 미국 CCPA, 한국 개인정보보호법 — 전 세계 어떤 규제도 통과합니다. 데이터를 수집하지 않으니 규제 위반 가능성 자체가 0%입니다.

② 사용자 신뢰

치매·두피·자율신경 등 가장 민감한 의료 데이터를 다루지만 서버 전송 0건. 사용자가 F12 콘솔에서 Network 탭을 열어 직접 확인 가능합니다.

③ 비용 효율성

사용자 1억 명이 와도 서버비 폭증 X. Local Match Caching으로 API 호출 90% 절감. 비즈니스 마진율 글로벌 최고 수준.

🩺 C-39 두피 케어

World First Fusion · STP Score · K-한방 변증 12개국어

1. 세계 최초 융합 (World First Fusion)

기존 두피 진단 앱들이 단순 확대 카메라로 표면만 보여줄 때, CGO-FULI는 두피 홍반(Erythema) + 자율신경(rPPG)을 동시에 실측하는 세계 최초의 융합 모델을 구현했습니다.

STP Score 알고리즘

STP Score = Erythema × BPM × HRV

• Erythema: Sobel Edge 필터로 두피 홍반 정밀 측정
• BPM: rPPG로 실시간 심박수 측정 (비접촉)
• HRV: 자율신경 균형도 (RMSSD, SDNN)

→ 단순 "빨갛다"가 아닌 "왜 빨간가"의 근본 원인을 수학적으로 도출

2. 7부위 정밀 측정

  • Phase 1 (안정 측정): 얼굴 30초 rPPG + 혀 20초 한방 변증
  • Phase 2 (두피 정밀): 정수리 30초 · M자 좌측 20초 · M자 우측 20초 · 정중선 20초 · 후두부 20초

3. K-한방 변증 5종 패턴

한의학에서 두피는 "髮者血之餘(머리카락은 혈의 나머지)"라 합니다. CGO-FULI는 5종 한방 변증 패턴을 수학적으로 매핑하여 12개 국어로 제공합니다.

변증 패턴 한방 의학적 의미 현대 의학 매핑
기혈양허(氣血兩虛) 에너지·혈액 부족 저혈압 + 만성피로
습열내문(濕熱內蘊) 체내 습기·열 정체 지루성 두피염
상열하한(上熱下寒) 두피열 + 손발 차가움 자율신경 불균형

🧠 C-39 치매 예방 체크

50문항 + rPPG 5분 자율신경 실측 · 천장 효과 완벽 극복

1. 기존 글로벌 치매 앱의 치명적 한계

루모시티, 알츠가드 등 기존 앱은 "맞혔냐 틀렸냐"만 봅니다. 고학력 사용자가 집중하면 초기 경도인지장애(MCI)를 숨길 수 있는 천장 효과(Ceiling Effect)가 의학적 한계로 지적되어 왔습니다.

2. C-39의 혁신 — 의지로 속일 수 없는 인체 물리 신호

문제 풀이 중 발생하는 전두엽 과부하를 안면 rPPG로 실시간 다이렉트 스캔합니다.

• 반응 속도 지연 (ms 단위) → 인지 처리 속도 측정
• HRV RMSSD 붕괴 → 자율신경 스트레스 포착
• 미세 혈압 변동성 (BPV) → 혈관 반응 측정

→ 인간 의지로 위조 불가능한 정직한 물리 신호

🛰️ NASA 연동 만세력

우주 물리 데이터 + 자율신경 동기화 · 세계 유일

1. 세계 유일의 우주-인체 동기화 엔진

단순 텍스트 기반 사주 앱이 아닙니다. NASA의 실제 태양황도 데이터와 실시간 위성 기상 정보를 자이로(나침반) 센서와 결합하여 사용자의 환경 스트레스 및 생체 바이오리듬(ILI 지수)을 실측합니다.

2. ILI-RBE v2.0 알고리즘

ILI (Integrated Life Index)
= 오행균형 + 일간강도 + 동양점수 + 서양점수

• 오행균형: 사주 5요소 균형도 (%)
• 일간강도: 본인 핵심 에너지 (0~1)
• 동양: 한방 + 동양철학 점수 (0~100)
• 서양: 점성학 + 통계 점수 (0~100)
