# CGO-FULI · 1창 (뼈대 · 입구 · 대시보드 · 번호 번역)

index.html          앱 본체 (영어가 본체 · 번호 자리 · 속 페이지는 <template>)
lang/ko.json        한국어 팩
lang/ja.json        일본어 팩
lang/zh.json        중국어(간체) 팩
lang/zh-Hant.json   중국어(번체) 팩
lang/ru.json        러시아어 팩
lang/english.json   영어 원문 전체 (번역 의뢰용 · 번호:영문)

## 쓰는 법
폴더 그대로 웹서버에 올리면 됩니다. (파일을 직접 더블클릭하면 브라우저 보안 때문에
lang/*.json 을 못 읽습니다 — 로컬에서 볼 때는 간단한 서버로 여세요.)

## 네 가지 원칙
① 영어가 본체       HTML 글자는 전부 영어. 영어 사용자는 번역 동작 0.
② 번역은 번호로     [data-k]="번호" 자리에 팩의 값을 쓴다. 글자를 읽지 않는다.
                    언어가 21개로 늘어도 자리 수가 같으므로 전환 시간은 그대로.
③ 보이는 것만       속 페이지는 <template> 안에 잠들어 있다가 누를 때 붙는다.
④ 사전은 최소       화면 자리는 전부 번호. 사전은 결과 텍스트 전용.

## 번역 추가하는 법
1. lang/english.json 을 통째로 번역기(제미나이)에 넣습니다.
2. 나온 결과를 lang/<코드>.json 으로 저장합니다. (번호는 그대로 두세요)
3. index.html 의 언어 목록에서 그 언어의 마지막 값을 1 로 바꾸면 활성화됩니다.
   예) ["es","Español","ES",0]  →  ["es","Español","ES",1]

아랍어(ar)는 오른쪽에서 왼쪽으로 흐르므로 화면 배치 작업이 따로 필요합니다.

## 팩 크기
ko 159자리 · ja/zh/zh-Hant/ru 각 94자리 — 한 언어당 5~9KB.
